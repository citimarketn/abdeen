# عابدين — Abdeen Online Store

> **نعتذر منكم عملاء متجر عابدين الكرام:** تم نقل المتجر بالكامل إلى الرابط الرسمي الجديد لتقديم تجربة تسوق أسرع وأفضل.
>
> 👉 **[اضغط هنا للانتقال إلى متجر عابدين الرسمي (abdeen.vercel.app)](https://abdeen.vercel.app)**

متجر إلكتروني عربي (RTL) بتصميم عصري فاخر، مع لوحة تحكم شاملة وأمان متعدد الطبقات — مبني بـ **Next.js 16 (App Router)** و **PostgreSQL + Drizzle ORM**.

## المتجر
- رئيسية فاخرة: Hero بخلفية وحركة قابلتان للتحكم، تشكيلات مميزة، عروض، الأكثر مبيعًا، آراء حقيقية، بانر عرض قابل للتعديل بالكامل (صورة + نصوص + رابط)، أسئلة شائعة — وكل قسم يمكن إخفاؤه أو إظهاره من لوحة التحكم.
- شبكة منتجات بفلاتر (قسم، سعر، تقييم، عروض، توافر) و5 طرق ترتيب وبحث فوري.
- صفحة منتج: ألبوم صور (حتى 4)، **فيديو يوتيوب** للمنتج، مقاسات وألوان، مدة توصيل خاصة بالمنتج، تقييمات محفوظة في قاعدة البيانات.
- سلة منبثقة بحالة محفوظة وخلفية قابلة للتحكم، وإتمام طلب (COD / بطاقة) مع رقم متابعة وزمن حالة الطلب.
- خلفية عامة للموقع + خلفية صفحة المنتجات + خلفية السلة — كلها من الإعدادات.
- أيقونات السوشيال ميديا في الفوتر: فيسبوك، إنستغرام، يوتيوب، تيليجرام.
- زر «مساعد عابدين الذكي» عائم — مهيأ للربط المستقبلي بوكيل ذكاء اصطناعي (حاليًا يوجّه الزائر إلى واتساب).
