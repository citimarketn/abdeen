# عابدين — Abdeen Online Store
> **نعتذر منكم عملاء متجر عابدين الكرام:** تم نقل المتجر بالكامل إلى الرابط الرسمي الجديد لتقديم تجربة تسوق أسرع وأفضل.
>
> 👉 **[اضغط هنا للانتقال إلى متجر عابدين الرسمي (abdeen.vercel.app)](https://abdeen.vercel.app)**
متجر إلكتروني عربي (RTL) بتصميم عصري فاخر، مع لوحة تحكم شاملة وأمان متعدد الطبقات — مبني بـ **Next.js 16 (App Router)** و **PostgreSQL + Drizzle ORM**.

## المتجر
- رئيسية فاخرة: Hero بخلفية وحركة قابلتان للتحكم، تشكيلات مميزة، عروض، الأكثر مبيعًا، آراء حقيقية، بانر عرض قابل للتعديل بالكامل (صورة + نصوص + رابط)، أسئلة شائعة — وكل قسم يمكن إخفاؤه أو إظهاره من لوحة التحكم.
- شبكة منتجات بفلاتر (قسم، سعر، تقييم، عروض، توافر) و5 طرق ترتيب وبحث فوري.
- صفحة منتج: ألبوم صور (حتى 4)، **فيديو يوتيوب** للمنتج، مقاسات وألوان، مدة توصيل خاصة بالمنتج، تقييمات محفوظة في قاعدة البيانات.
- سلة منبثقة بحالة محفوظة وخلفية قابلة للتحكم، وإتمام طلب (COD / بطاقة) مع رقم متابعة وزمن حالة الطلب.
- خلفية عامة للموقع + خلفية صفحة المنتجات + خلفية السلة — كلها من الإعدادات.
- أيقونات السوشيال ميديا في الفوتر: فيسبوك، إنستغرام، يوتيوب، تيليجرام.
- زر «مساعد عابدين الذكي» عائم — مهيأ للربط المستقبلي بوكيل ذكاء اصطناعي (حاليًا يوجّه الزائر إلى واتساب).

## لوحة التحكم (`/admin`) — للمالك والمشرفين فقط
- **الدخول آمن بثلاث طبقات:** (1) إيميل + كلمة مرور، (2) ثلاث أكواد حماية قوية يحددها المالك، أو **تسجيل دخول بحساب جوجل** للمالك (تفعيل بإدخال Google Client ID في الإعدادات).
- **المالك فقط:** قسم «الفريق والصلاحيات» — إضافة مشرفين بإيميلات وكلمات مرور خاصة، ومنح كل مشرف صلاحيات محددة (منتجات، طلبات، تقييمات، أقسام، إعدادات، لوحة معلومات) يمكن تعديلها لحظيًا أو إيقاف الحساب.
- لوحة معلومات: إيرادات، طلبات، مخزون منخفض، الأكثر مبيعًا.
- منتجات: إضافة/تعديل/حذف مع **رفع الصور من الجهاز (حتى 4)** أو روابط مباشرة، رابط فيديو يوتيوب، مدة توصيل، شارات، إخفاء/إظهار.
- أقسام: إضافة، تعديل الاسم، إظهار/إخفاء، حذف.
- طلبات بتحديث حالة، تقييمات بإشراف كامل.
- إعدادات حية: الهوية، شريط الإعلانات، الـ Hero، الخلفيات وحركاتها، البانر، أقسام الرئيسية، الشحن المجاني (اختياري) والرسوم، التواصل، السوشيال ميديا، الأمان.

- إيميل المالك: `abdeenali520@gmail.com``

## ملاحظات أمنية قبل النشر
- غيّر أكواد الحماية وكلمة مرور المالك من الإعدادات.
- لتفعيل دخول جوجل: أنشئ OAuth Client (Web) في Google Cloud Console وأضف الـ Client ID في الإعدادات → الأمان.
- الصور المرفوعة تُحفظ في `public/uploads/products` — انقلها إلى Cloud Storage عند الاستضافة السحابية.
- الربط المستقبلي بالوكيل الذكي: استمع على مسار `/api/orders` الجديد وأدر الطلب للوكيل (واتساب API / Gemini).
